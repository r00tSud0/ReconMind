When something goes wrong

Each message says what happened, what it means for the results, and what to do next. These appear on the screens named above each one.

On the report, when the LLM is down
The AI summary could not be written

OpenRouter answered with 429, too many requests. Every finding below comes straight from the tools and is complete. Only the written summary and the attack path text are missing.

On Live run, when a tool is missing
Crypto Check testssl.sh
Skipped because testssl.sh is not installed. The rest of the scan carries on.
Install it on Kali, then run the scan again:
sudo apt install testssl.sh
On the report, when NVD does not answer
CVEs were not checked for 11 services

NVD did not answer after 3 tries. This does not mean those services have no CVEs. Exploit Hunt results are not affected.

On the report, after packet loss
2 ports could not be confirmed

Ports 1524 and 3632 answered in the fast pass but not in the detail pass, usually because packets were dropped. They are not counted as findings.

On the report, when the ATT&CK model is missing
Mapped with rules only

The fine-tuned model was not found in models/attack_mapper_run3, so ATT&CK techniques come from the built-in rules. Copy the model folder there to turn it back on.
