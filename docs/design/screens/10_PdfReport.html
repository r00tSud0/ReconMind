Executive summary

Overall risk: Critical Remote code execution is possible without a password.

The host runs two services with known backdoors, vsftpd 2.3.4 on port 21 and UnrealIRCd 3.2.8.1 on port 6667. Either one lets an attacker open a command shell on the host with no password. Samba 3.0.20 offers a third way in. FTP and IRC should be taken offline first, then Samba patched, Telnet closed and MySQL limited to localhost.
